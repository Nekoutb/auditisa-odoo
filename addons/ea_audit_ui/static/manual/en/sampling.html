Sampling

Draw a sample, record the audited values and conclude.

Who: the engagement team. Roles that only read (for example the quality reviewer) see the page in read-only mode.

Drawing a sample

The Sampling page holds every sample of the engagement, with its reason, so each draw can be explained and repeated.

  1. Click Draw from a dataset (or Draw the sample from Procedure design, which fills it for you).
  2. Choose the Dataset and the method: Random, Systematic, Monetary unit (MUS) or Key items + random. Set the Sample size, and the Key-item threshold, Confidence and Expected misstatement where asked.
  3. To force a size, fill Size typed by hand and Why the size is typed by hand.
  4. Click Draw. Then enter the Audited value of every item.
  5. Click Record the conclusion, or Extend the sample if the projected error is above the tolerable misstatement. A projected error goes to the summary of audit differences (C1.1).
