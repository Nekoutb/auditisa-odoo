Bringing an older engagement up to the current scope

Move an engagement opened before 17 November 2026 to the current task scope.

Who: a partner on the team (not the engagement quality reviewer).

Applying the current task scope

Engagements opened before 17 November 2026 keep the tasks they were opened with: no task appears or disappears on a live engagement by itself. To move such an engagement to the current scope:

  1. Open the Engagement record from the gear icon.
  2. Click Apply the current task scope and confirm.

Tasks the current scope adds come onto the engagement file. Tasks that hold no work and no longer apply are hidden. Tasks that hold work stay. The result is written to the activity trail. The button disappears once applied.
