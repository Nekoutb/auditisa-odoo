Analytics and the data tools

Record substantive analytical procedures, and use the analysers that do part of the work from the client's files.

Who: the engagement team. Roles that only read (for example the quality reviewer) see the pages in read-only mode.

Substantive analytics

Substantive analytics records an analytical procedure as evidence: lead index, assertion, expectation, actual figure, threshold (a share of performance materiality, set by risk), difference and conclusion. Click Save a procedure to add one.

The analysers

The Data analytics tile opens the analysers. Each one lists the uploads of its kind, with Import a dataset and Download the template:

AnalyserWhat it holds
Trial balance analyzerUpload, check and map the trial balance.
General ledger analyzerThe journal-entry population, its checks and The thirty analytics.
Accounts receivable analyzer / Accounts payable analyzerOpen items and ageing, Reconcile to the control account, Export the aging.
Supplier statementsStatements against the payables ledger.
Bank analyzerBank statements and outstanding items.
Inventory analyzerThe inventory listing, used for the test counts.
Fixed assets analyzerThe register, used by K-M1 and K-M2.
Payroll analyzerThe payroll register and its agreement to the balance.
