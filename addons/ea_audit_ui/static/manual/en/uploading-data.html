Uploading the client's data

Upload the client's own figures (trial balance, ledger, payroll and others) so that the tools can work on them.

Who: any team member except a read-only user can upload. Everyone on the team can read the uploads.

Where to upload

  1. Open the engagement and click the tools icon (Engagement tools) in the top bar.
  2. Click the Data analytics tile. A second page of tiles opens, one per kind of data.
  3. Click the tile you need, for example Trial balance analyzer or Payroll analyzer.
  4. Click Import a trial balance (trial balance) or Import a dataset (all others).
Tip Each tile offers Download the template: an Excel file with the expected columns. Send it to the client to save time at matching.

Files are accepted as .csv or .xlsx. Mandatory columns are needed for the import; the others are optional and make the analysis richer.

Optional payroll columns

The payroll upload accepts 13 more columns. None is required, and each is marked Improves the analysis on the matching screen, where a line shows how many were matched (for example 5 of 13 matched). The more you provide, the more the payroll analytical review can compare with the prior year: gross pay, headcount, components of pay, joiners and leavers, average pay and taxes on pay. In the downloadable template these column titles are shaded.

Importing a file, step by step

The import has three steps. Nothing is saved until you click Import at the end.

1 Upload

  1. Check the Kind of data.
  2. Choose the Timing (see the table below).
  3. Choose the file in File (.csv, .xlsx). Leave The first line holds the column titles ticked if it does.
  4. Click Read the file.

2 Match the columns

Each line is one column of the client's file: Column in your file, its First three values, and the AuditISA field it feeds. How it was matched reads Matched automatically, Chosen by you or Not recognised.

  1. Check each automatic match. To change one, open the list in AuditISA field and choose another field, or Do not import.
  2. Make sure every field marked mandatory has a column. The message at the top tells you what is still missing.
  3. If dates or amounts look wrong, set the Decimal separator, Date format, Column separator or Sheet.
  4. For a general ledger without a single entry number, use Entry identified by several columns.
  5. Click Check the file.
Tip Leave Remember this matching for this client's next file of this kind ticked. Next year the same layout is matched for you.

3 Check

The tool reads every row and shows the rows read, the totals and, for a ledger, whether debits equal credits. Each point found is marked Left out, Imported with a warning or Blocks the import. If you see The file can be imported., click Import. If not, correct the file or click Back to matching.

Careful A general ledger whose debits and credits do not balance is refused. Ask the client for a complete extract rather than editing it yourself.

Timing and uploads for next year

TimingUse it for
Pre-auditThe client's figures before your adjustments. A pre-audit trial balance drives the engagement file (lead schedules, materiality, significant accounts).
Post-auditThe figures after the adjustments agreed.
Prior yearLast year's figures, for comparisons.
Subsequent period (next year)Data of the year after the one audited, for the cut-off procedures and the search for unrecorded liabilities. It never stands in for the year audited. A next-year ledger covering fewer than 30 days after the year end is too short for cut-off work.
