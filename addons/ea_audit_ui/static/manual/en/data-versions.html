Versions of an upload

Every upload is kept: see which one the work rests on, and delete an upload made by mistake.

Who: any team member except a read-only user can delete an upload. Everyone on the team can read the uploads.

Versions

Every upload is kept. For each kind and timing, the latest upload is the one In use; an earlier one shows Superseded on and stays in the list as a record. The list also shows Imported on, Imported by, the File, the Rows and the Total amount, so you can always tell which file the work rests on.

Deleting an upload

  1. Click the bin icon (Delete this upload) at the end of the line, or the button of the same name on the upload.
  2. Read the confirmation: it says what will be removed and which earlier upload, if any, takes over.
  3. Click Delete, or Keep it to cancel.

If you delete the upload in use, the previous one of the same kind and timing is in use again.
