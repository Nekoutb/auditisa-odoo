The audit file index

The list of every task an engagement file can hold, in the order of the audit.

Who: partners and the firm administrator.

Reading the index

Click the cog (Settings), then File index. The Audit file index lists every task an engagement file can hold, in the order of the audit: Order, code, title, section, Phase, tier (Core, Standard, Extended) and whether it is conditional. It is the same for every firm and cannot be edited here. Use the filters Core and Conditional, or group by Phase or Section.
