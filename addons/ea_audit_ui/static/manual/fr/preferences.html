Vos préférences et la sécurité de connexion

Vos informations personnelles, votre mot de passe, votre langue et la vérification en deux étapes à la connexion.

Qui : tout le cabinet, chacun pour son propre compte.

Vérification en deux étapes

Vous pouvez protéger votre compte par une seconde étape à la connexion : après votre mot de passe, AuditISA demande un code à six chiffres fourni par une application d'authentification sur votre téléphone (par exemple Google Authenticator ou Microsoft Authenticator). Quelqu'un qui découvre votre mot de passe ne peut toujours pas entrer sans votre téléphone. Les associés et les administrateurs en particulier devraient l'activer.

  1. Cliquez sur la roue dentée (Paramètres) dans la barre du haut, puis sur Préférences.
  2. Ouvrez l'onglet Sécurité.
  3. Cliquez sur le bouton qui active l'authentification à deux facteurs et confirmez votre mot de passe.
  4. Scannez avec votre application d'authentification le code carré affiché à l'écran.
  5. Tapez le code à six chiffres affiché par l'application, puis confirmez.
Bon à savoir Les clés API sont désactivées sur le serveur de chaque cabinet, pour tous les utilisateurs : elles permettraient de contourner la vérification en deux étapes.

Choisir votre langue

AuditISA fonctionne en anglais et en français. Cliquez à tout moment sur EN ou FR dans la barre du haut. La page se recharge dans cette langue et AuditISA retient votre choix pour vos prochaines visites. Les nouveaux comptes démarrent dans la langue du cabinet, que fixe l'administrateur du cabinet ; chacun choisit ensuite la sienne.

Votre profil

La droite de la barre du haut affiche votre nom, votre rôle dans le cabinet et vos initiales. Pour consulter ou modifier vos propres informations :

  1. Cliquez sur la roue dentée (Paramètres), puis sur Préférences.
  2. Modifiez ce dont vous avez besoin, par exemple votre signature d'e-mail ou la façon dont vous recevez les notifications.
  3. Pour changer votre mot de passe, ouvrez l'onglet Sécurité et cliquez sur Changer le mot de passe. Vous tapez votre mot de passe actuel, puis le nouveau.
  4. Cliquez sur Mettre à jour les préférences.

Si vous avez oublié votre mot de passe, cette fenêtre vous est inaccessible : utilisez Mot de passe oublié ? sur la page de connexion, ou demandez un Nouveau lien de mot de passe à l'administrateur du cabinet (voir Première connexion).

Bon à savoir Vous ne pouvez pas changer votre propre rôle. Seul l'administrateur du cabinet change les rôles, et jamais le sien.
