L'index du dossier d'audit

La liste de toutes les tâches qu'un dossier de la mission peut contenir, dans l'ordre de l'audit.

Qui : les associés et l'administrateur du cabinet.

Lire l'index

Cliquez sur la roue dentée (Paramètres), puis sur Index du dossier. L'Index du dossier d'audit liste toutes les tâches qu'un dossier de la mission peut contenir, dans l'ordre de l'audit : Ordre, code, intitulé, section, Phase, niveau (Socle, Standard, Étendu) et caractère conditionnel ou non. Il est le même pour tous les cabinets et ne peut pas être modifié ici. Utilisez les filtres Socle et Conditionnelle, ou regroupez par Phase ou par Section.
