Applications informatiques et contrôles informatiques

Applications informatiques et CGI (S2.3 à S2.5) liste chaque application citée dans vos catégories d'opérations. Pour chacune, renseignez ses Couches (application, base de données, système), une stratégie et une note :

  • S'appuyer sur les processus informatiques : tester les CGI
  • Tester directement les contrôles automatisés, à chaque période
  • Entièrement substantif : aucun appui sur les contrôles informatiques

Une fois les travaux terminés, cliquez sur Enregistrer la conclusion S2.5 : Permettent de s'appuyer, Ne permettent pas de s'appuyer ou Mitigée. Cette conclusion alimente l'évaluation combinée des risques.

Le processus de clôture

Le Processus de clôture (S1.4) est un formulaire en quatre parties : A. Le chemin critique de la clôture, B. Risques d'anomalie, C. Changements et communications, D. Stratégie et confirmation.
