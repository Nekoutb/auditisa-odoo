Les versions d'un import

Chaque import est conservé : voyez celui sur lequel reposent les travaux, et supprimez un import fait par erreur.

Qui : tout membre de l'équipe, sauf un utilisateur en lecture seule, peut supprimer un import. Tous les membres de l'équipe peuvent consulter les imports.

Les versions

Chaque import est conservé. Pour chaque type et chaque moment, l'import le plus récent est celui qui est Utilisé ; un import antérieur affiche Remplacé le et reste dans la liste pour mémoire. La liste indique aussi Importé le, Importé par, le Fichier, les Lignes et le Montant total, de sorte que vous savez toujours sur quel fichier reposent les travaux.

Supprimer un import

  1. Cliquez sur l'icône de corbeille (Supprimer cet import) au bout de la ligne, ou sur le bouton du même nom dans l'import.
  2. Lisez la confirmation : elle indique ce qui sera supprimé et quel import antérieur, le cas échéant, prend le relais.
  3. Cliquez sur Supprimer, ou sur Conserver pour annuler.

Si vous supprimez l'import utilisé, le précédent du même type et du même moment redevient utilisé.
