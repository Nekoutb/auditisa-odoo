La phase Exécution et les tests des contrôles

Ce que contient la phase Exécution, l'ordre de travail, et la façon de tester les contrôles sur lesquels vous vous appuyez.

Qui : l'équipe réalise les travaux. Les rôles en lecture seule (par exemple le réviseur qualité de la mission) voient toutes les pages en lecture seule.

Ce que contient la phase

Cliquez sur Exécution dans la barre du haut. L'anneau Exécution regroupe Tests de contrôles (E1), Mises à jour des contrôles (E2), Procédures substantives (E4 et E5), Procédures spécifiques (E3, E6) et Registres, soldes d'ouverture (E6). Le test des écritures de journal (E3.1) se trouve dans le groupe des procédures spécifiques, sous son propre code.

Un clic sur Procédures substantives ouvre directement la page Procédures de substance, et non une liste de tâches. Le chiffre entre parenthèses à côté indique le nombre de comptes conçus en S5.5.

Travaillez dans cet ordre : concevez les procédures, tirez les échantillons, réalisez les travaux compte par compte, puis enregistrez les conclusions.

Tests des contrôles (E1.2)

Sur la page Échantillonnage, la section Contrôles à tester présente chaque contrôle coché À tester.

  1. Saisissez les Occurrences dans l'année du contrôle, puis cliquez sur Tirer l'échantillon.
  2. Testez les occurrences tirées. Cliquez sur Importer la grille de test (colonnes : référence, date, description, puis une colonne par attribut avec pass, fail ou na), ou sur Enregistrer un test pour les saisir un par un.
  3. Lisez la Conclusion de fonctionnement.
Attention Si un contrôle testé n'est pas efficace, le risque combiné des assertions qu'il couvre passe à Ne pas s'appuyer, et la conception des procédures propose davantage de tests de détail. Enregistrez la déficience sous forme de constat.
